# 和風 3,570 英文單字學習室

## 專案內容
- 3,000 筆核心高頻英文單字
- 570 筆 Academic Word List（AWL）資料欄位
- 首頁與 3 幕故事輪播
- 日式和風視覺：米白、木質、留白、圓角
- 搜尋、分類、排序、新增、刪除、整理
- 瀏覽器 Web Speech API 英文發音播放
- CSV + MySQL 資料庫規格

## 重要資料說明
本包提供 3,570 筆資料結構與可匯入資料檔；其中 AWL 與「完整 3,000 核心詞表」的「來源版本」應在正式發布前指定。為避免把不同詞表版本混成同一套，CSV 保留 collection_note 欄位供稽核。正式學習產品建議固定詞表版本、來源網址、授權條款與版本號。

## 發音
目前前端以 SpeechSynthesis 播放單字。若要 3,570 個獨立 MP3/OGG 音檔，可再接 TTS 服務，將 audio_url 存入資料庫。

## 安裝
1. 將資料夾放入網站目錄。
2. 直接開 index.html 可預覽介面。
3. CSV 可匯入 MySQL；先執行 database_schema.sql，再依實際 CSV 匯入。
